🌟 About The Project

OpportunityHub is a responsive web platform created to help students discover educational and career opportunities from one simple interface.

Whether you are looking for a scholarship 🎓, an internship 💼, a free course 📚, or a job 🚀, OpportunityHub provides an easy way to search, filter, save, and explore opportunities.

💡 "Your next opportunity could change your future."

🧠 How It Works

Opportunity data is currently stored inside JavaScript:

const opportunities = [
  {
    id: 1,
    title: "Global Student Scholarship",
    category: "Scholarship",
    organization: "Education Foundation",
    location: "Online",
    deadline: "30 November 2026",
    description: "Financial support for students pursuing higher education."
  }
];


JavaScript dynamically creates the opportunity cards and handles:
